# Plan: `make app sandbox=1` — Reproducible Sandbox Launch

## Goal

Add an optional boolean parameter to `make app` (and `make dev`) that, when set, bootstraps a fresh sandbox fixture in `/tmp/omux-sandbox` and launches OpenMUX against that isolated environment instead of the real user data.

Usage: `make app sandbox=1` or `make dev sandbox=1`

---

## Key Finding: Two Separate State Roots

OpenMUX state lives in two separate locations:

| State | Default Path | Controlled By |
|-------|-------------|---------------|
| Config, hooks, plugins, themes, socket | `~/.omux/` | `OMUX_HOME` env var (already works) |
| Workspace state (current.json), scrollback, backups | `~/Library/Application Support/OpenMUX/` | **Hardcoded — no override exists yet** |

The plan adds an `OMUX_APP_SUPPORT_DIR` env var override to `WorkspacePersistenceStore` so the sandbox can redirect workspace persistence to `/tmp/omux-sandbox/AppSupport/`.

---

## Implementation Steps

### Step 1: Add `OMUX_APP_SUPPORT_DIR` env var to `WorkspacePersistenceStore`

**File:** `Sources/OmuxCore/WorkspacePersistenceStore.swift`

Modify `appStateDirectoryURL()` (line ~135):

```swift
static func appStateDirectoryURL() -> URL {
    if let override = ProcessInfo.processInfo.environment["OMUX_APP_SUPPORT_DIR"] {
        return URL(fileURLWithPath: override, isDirectory: true)
            .appendingPathComponent("WorkspaceState", isDirectory: true)
    }
    return FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
        .appendingPathComponent("OpenMUX", isDirectory: true)
        .appendingPathComponent("WorkspaceState", isDirectory: true)
}
```

Apply the same pattern to `appScrollbackDirectory()` and `appBackupDirectory()` so all three paths are redirected consistently.

### Step 2: Create `Scripts/setup-sandbox.sh`

This script:
1. Wipes and recreates `/tmp/omux-sandbox/` (both OMUX_HOME subtree and AppSupport subtree)
2. Writes `/tmp/omux-sandbox/config.toml` with test-friendly defaults
3. Creates stub directories: `hooks/`, `themes/`, `plugins/`, `state/`
4. Creates git repos for worktrees at `/tmp/omux-sandbox/worktrees/<name>/` (2–3 repos, each with a bare `git init + commit`)
5. Writes `/tmp/omux-sandbox/AppSupport/WorkspaceState/current.json` — a full `WorkspacePersistenceSnapshot` fixture with:
   - 2 workspaces (`alpha`, `beta`)
   - Each workspace: 2 tabs
   - Each tab: 2-pane horizontal split, each pane pointing to a worktree working directory
   - `activeWorkspaceID` set to workspace `alpha`
6. Creates `/tmp/omux-sandbox/AppSupport/WorkspaceState/` and `Scrollback/` and `WorkspaceBackups/` directories
7. Prints a summary of the setup

**Fixture JSON structure** (abridged):
```json
{
  "workspaces": [
    {
      "id": "sandbox-ws-alpha",
      "generatedName": "alpha",
      "customName": null,
      "rootPath": "/tmp/omux-sandbox/worktrees/alpha",
      "tabs": [
        {
          "id": "sandbox-tab-alpha-1",
          "title": "main",
          "focusedPaneID": "sandbox-pane-alpha-1a",
          "rootLayout": {
            "split": {
              "axis": "horizontal",
              "proportions": [0.5, 0.5],
              "children": [
                { "paneStack": { "id": "sandbox-stack-alpha-1a", "panes": [<pane-alpha-1a>], "focusedPaneID": "sandbox-pane-alpha-1a" } },
                { "paneStack": { "id": "sandbox-stack-alpha-1b", "panes": [<pane-alpha-1b>], "focusedPaneID": "sandbox-pane-alpha-1b" } }
              ]
            }
          }
        },
        { "id": "sandbox-tab-alpha-2", ... }
      ],
      "focusedTabID": "sandbox-tab-alpha-1",
      "floatingPaneModals": []
    },
    { "id": "sandbox-ws-beta", ... }
  ],
  "activeWorkspaceID": "sandbox-ws-alpha"
}
```

Each pane's `content`:
```json
{
  "type": "terminal",
  "session": {
    "id": "sandbox-session-alpha-1a",
    "shell": "/bin/zsh",
    "workingDirectory": "/tmp/omux-sandbox/worktrees/alpha",
    "environment": {}
  }
}
```

### Step 3: Modify `Makefile`

**`dev` target** — add `sandbox=1` conditional:

```makefile
dev:
ifeq ($(sandbox),1)
	@echo "[sandbox] Setting up sandbox at /tmp/omux-sandbox..."
	@./Scripts/setup-sandbox.sh
	OMUX_HOME=/tmp/omux-sandbox \
	OMUX_APP_SUPPORT_DIR=/tmp/omux-sandbox/AppSupport \
	GHOSTTY_RESOURCES_DIR="$(CURDIR)/Vendor/ghostty/zig-out/share/ghostty" \
	$(SWIFT) run OpenMUXApp
else
	GHOSTTY_RESOURCES_DIR="$(CURDIR)/Vendor/ghostty/zig-out/share/ghostty" $(SWIFT) run OpenMUXApp
endif
```

`app: dev` remains unchanged — it inherits the `sandbox` variable automatically.

**`help` target** — add a line:
```
  make app sandbox=1  Launch OpenMUXApp with a fresh reproducible sandbox setup
```

## Worktree Setup in Sandbox Script

```bash
for name in alpha beta gamma; do
  dir="/tmp/omux-sandbox/worktrees/$name"
  mkdir -p "$dir"
  git -C "$dir" init -q
  git -C "$dir" config user.email "sandbox@omux"
  git -C "$dir" config user.name "Sandbox"
  echo "# $name" > "$dir/README.md"
  git -C "$dir" add README.md
  git -C "$dir" commit -q -m "sandbox init"
done
```

## Non-Goals

- No changes to IPC, hooks, or CLI for this feature
- The sandbox does not persist between runs (always reset on `sandbox=1`)
- No UI indicator that sandbox mode is active (out of scope for now)
