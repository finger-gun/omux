# Plan: Git Worktrees Sidebar Widget

## Overview

Introduce a new **right sidebar panel** that is widget-aware: it can host multiple widgets (starting with Git Worktrees; Agent Sessions moves there later or coexists). The initial deliverable is a **Git Worktrees widget** that:

- Lists all worktrees for the repo of the currently focused pane (via `git worktree list --porcelain`)
- Navigates the focused pane to a worktree directory on click (cd + set CWD)
- Lets the user delete a worktree from the list (with confirmation)
- Lets the user create a new worktree (with branch selection from existing branches)

---

## Architecture decision

The existing `WorkspaceVaultSidebarView` is the right sidebar, gated by `vaultConfiguration.enabled`. The new design makes the right sidebar a **general-purpose widget host** rather than a Vault-only panel.

### Right Sidebar Refactor

Rename/repurpose `WorkspaceVaultSidebarView` → `WorkspaceRightSidebarView` (or keep the class name internally and just change behaviour):

- The right sidebar is always added to the view hierarchy (not gated on vault).
- Its visibility is controlled by a new toggle (or reuse the vault toggle button).
- It contains a vertical `NSStackView` of widget sections (similar to how the left sidebar has `WorkspaceSidebarSectionView`).
- Each widget section has a collapsible header + content area.

> **Implementation note:** To minimise risk, we can keep `WorkspaceVaultSidebarView` as-is and introduce `WorkspaceRightSidebarView` as a new wrapper that contains both `WorkspaceVaultSidebarView` (when vault enabled) and `GitWorktreesSidebarWidget`. Alternatively, move the vault content into a widget section inside a new generic right sidebar. The simpler path is to add the worktree widget as a sibling widget *inside* the existing vault sidebar container, regardless of vault being enabled. This avoids a full sidebar refactor and lets us ship the feature first.

**Chosen approach for this change:**
1. Decouple the right sidebar visibility from vault being enabled — it should show whenever *any* widget has content (worktrees always apply when in a git repo; vault only when enabled).
2. Add `GitWorktreesSidebarWidget` as a new widget section inside `WorkspaceVaultSidebarView` (renamed to `WorkspaceRightSidebarView` to reflect the broader purpose).
3. Agent Sessions section remains intact as a widget section within the same sidebar.

## Components

### 1. `GitWorktree` model (`OmuxAppShell`)

```swift
struct GitWorktree: Equatable {
    let path: String          // absolute path
    let branch: String?       // nil = detached HEAD
    let isMainWorktree: Bool
    let isCurrentRepo: Bool   // true if this is the focused pane's own worktree
}
```

### 2. `GitWorktreeResolver` (`OmuxAppShell`)

Runs git commands off the main thread:

- `listWorktrees(in directory: String) -> [GitWorktree]`
  - Runs: `git -C <dir> worktree list --porcelain`
  - Parses the porcelain output (worktree / HEAD / branch / bare / prunable fields)

- `listBranches(in directory: String) -> [String]`
  - Runs: `git -C <dir> branch --list --format=%(refname:short)`
  - Used for the "create worktree" branch picker

- `addWorktree(branch: String, fromRef: String?, at path: String, in directory: String) -> Result<String, Error>`
  - Runs: `git -C <dir> worktree add -b <branch> <path> [fromRef]`

- `removeWorktree(at path: String, in directory: String) -> Result<Void, Error>`
  - Runs: `git -C <dir> worktree remove <path>`

Reuse the `runGitOffMain` / `gitOutputOffMain` pattern from `OpenMUXAppDelegate`.

### 3. `GitWorktreesSidebarWidget` (NSView)

A self-contained `NSView` widget section with collapse/expand support:

**Header row (clickable to toggle collapse):**
- Disclosure chevron (`chevron.right` / `chevron.down` SF Symbol, matching the left sidebar workspace rows)
- Label: "GIT WORKTREES" (matching the style of "AGENT SESSIONS")
- Refresh button (arrow.clockwise SF Symbol) — hidden when collapsed
- Add button (plus SF Symbol) — hidden when collapsed; triggers the Create Worktree sheet

**List (hidden when collapsed):**
- `NSScrollView` → `FlippedStackView` of `WorktreeRowView` rows
- Empty state label: "No git repository" or "No worktrees"

**`WorktreeRowView`:**
- Branch name (or "detached HEAD") as primary label
- Shortened path as secondary label
- Delete button (trash SF Symbol) on hover/right — triggers removal confirmation

**Render method signature:**
```swift
func render(
    worktrees: [GitWorktree],
    isCollapsed: Bool,
    theme: WorkspaceShellTheme,
    onNavigate: @escaping (GitWorktree) -> Void,
    onDelete: @escaping (GitWorktree) -> Void,
    onCreate: @escaping () -> Void,
    onRefresh: @escaping () -> Void,
    onToggleCollapse: @escaping () -> Void
)
```

Collapse state is stored in `WorkspaceWindowController` (not in the view) and persisted via `UserDefaults`, matching how `collapsedWorkspaceIDs` works in the left sidebar.

## Collapsible Section Headers

Both the Git Worktrees widget and the Agent Sessions section get a **shared collapsible header pattern**:

### `CollapsibleSectionHeaderView` (private NSView)

A reusable header row used by each widget section:

```
[▶/▼ chevron] [SECTION TITLE]  [spacer]  [action buttons...]
```

- Clicking anywhere on the header (or the chevron specifically) fires `onToggle`
- Action buttons (refresh, add) are hidden when collapsed
- Chevron uses SF Symbols: `chevron.right` (collapsed) → `chevron.down` (expanded), matching the left sidebar disclosure pattern

```swift
final class CollapsibleSectionHeaderView: NSView {
    func render(
        title: String,
        isCollapsed: Bool,
        actionButtons: [NSButton],
        theme: WorkspaceShellTheme,
        onToggle: @escaping () -> Void
    )
}
```

### State persistence

Collapse states are tracked in `WorkspaceWindowController`:

```swift
private var isWorktreesSectionCollapsed: Bool   // persisted in UserDefaults
private var isAgentSessionsSectionCollapsed: Bool
```

UserDefaults keys: `"omux.rightSidebar.worktreesCollapsed"`, `"omux.rightSidebar.agentSessionsCollapsed"`

Toggling collapse triggers a lightweight `applyState()` pass (no git I/O needed).

### 4. Create Worktree Sheet

Presented as an `NSAlert`-style sheet or a small `NSPanel`:

- **Branch name** text field (auto-populated with `worktree/<uuid-prefix>` default, matching existing pattern)
- **Base branch** popup menu (populated from `listBranches`)
- **Create** / **Cancel** buttons

On confirm:
1. Run `addWorktree` off-main
2. On success: navigate the focused pane to the new worktree path (same as clicking the worktree row)
3. Refresh the worktree list

### 5. Modifications to `WorkspaceWindowController`

**State:**
```swift
private var worktrees: [GitWorktree] = []
private var worktreeBranches: [String] = []
```

**Triggering refresh:**
- When focused pane changes (already tracked via `applyState`)
- On explicit user refresh button press
- After create/delete operations

**`reloadWorktrees()`:**
```swift
private func reloadWorktrees() {
    guard let cwd = activeWorkspace()?.focusedPane?.workingDirectory else {
        worktrees = []
        applyState(...)
        return
    }
    Task.detached(priority: .userInitiated) { [weak self] in
        let list = GitWorktreeResolver.listWorktrees(in: cwd)
        await MainActor.run { [weak self] in
            self?.worktrees = list
            self?.applyState(...)
        }
    }
}
```

**Navigation on click (navigate focused pane):**
```swift
private func navigateToWorktree(_ worktree: GitWorktree) {
    // 1. Run `cd <path>` in the focused terminal
    try? runCommand(target: .focused, command: "cd \(worktree.path.shellEscaped)")
    // 2. Update the pane's tracked CWD
    try? setPaneWorkingDirectory(target: .focused, path: worktree.path)
}
```

**Delete worktree:**
- Show `NSAlert` confirmation sheet (matching `presentWorktreeRemovalPrompt` pattern)
- On confirm: run `removeWorktree` off-main, refresh list on completion

### 6. Right Sidebar Visibility Decoupling

Currently the sidebar width constraint is gated on `vaultConfiguration.enabled`. Change this:

- Right sidebar is always added to the view hierarchy with a width constraint.
- Visibility is toggled by the existing vault toggle button (rename it to "right sidebar toggle").
- Agent Sessions section within the sidebar is shown/hidden based on vault configuration.
- Worktrees section is always shown (but shows empty state when not in a git repo).

**`ShellLayoutMetrics.vaultSidebarWidth`** stays the same (280pt).

## Detailed Task Breakdown

1. **Create `GitWorktreeResolver.swift`** in `Sources/OmuxAppShell/`
   - `GitWorktree` model struct
   - `listWorktrees(in:)` — parse `git worktree list --porcelain`
   - `listBranches(in:)` — `git branch --list --format=%(refname:short)`
   - `addWorktree(branch:fromRef:at:in:)` — `git worktree add -b`
   - `removeWorktree(at:in:)` — `git worktree remove`

2. **Add `CollapsibleSectionHeaderView` class** (private, inside `WorkspaceWindowController.swift`)
   - Disclosure chevron + title label + spacer + action buttons
   - Click anywhere to toggle; chevron animates between `chevron.right` / `chevron.down`
   - Action buttons hidden when collapsed

3. **Add `GitWorktreesSidebarWidget` class** (inside `WorkspaceWindowController.swift` as a private final class, matching the existing pattern)
   - Uses `CollapsibleSectionHeaderView` for its header
   - Scrollable list with `WorktreeRowButton` items (hidden when collapsed)
   - Empty state handling
   - `render(worktrees:isCollapsed:theme:on*:)` method
   - `apply(theme:)` method

4. **Retrofit Agent Sessions section** to use `CollapsibleSectionHeaderView`
   - Replace the existing static header in `WorkspaceVaultSidebarView` with the new collapsible header
   - Wire `isCollapsed` state from the controller
   - Hide scroll content when collapsed

5. **Add `WorktreeRowButton` class** (private, inside `WorkspaceWindowController.swift`)
   - Branch label + path sublabel
   - Delete button (appears on hover)
   - Navigate callback on click

6. **Add Create Worktree sheet** (inline in `WorkspaceWindowController.swift`)
   - `showCreateWorktreeSheet(repoDirectory:branches:onConfirm:)` method
   - Uses `NSAlert` with an accessory view containing branch name field + base branch popup

7. **Decouple right sidebar from vault gate**
   - Remove `if vaultConfiguration.enabled` guards around sidebar width/layout
   - Always add `vaultSidebarView` (now `rightSidebarView`) to view hierarchy
   - Show/hide Agent Sessions section based on `vaultConfiguration.enabled`

8. **Wire state into `WorkspaceWindowController`**
   - Add `worktrees: [GitWorktree]` state
   - Add `isWorktreesSectionCollapsed` and `isAgentSessionsSectionCollapsed` (persisted in UserDefaults)
   - Add `reloadWorktrees()` method triggered on pane focus change
   - Pass all state to `rightSidebarView.render(...)` 
   - Implement `navigateToWorktree(_:)`, `deleteWorktreePrompt(_:)`, `deleteWorktree(_:)`, `createWorktreeSheet()`

## Open Questions / Decisions Made

| Question | Decision |
|----------|----------|
