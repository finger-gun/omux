# Security Policy

## Supported Versions

OpenMUX is currently in beta and has not reached 1.0 yet.

Security fixes are provided for the most recent released `0.x` version only. We do not maintain separate security patch branches for older beta releases.

| Version | Supported |
| ------- | --------- |
| Latest released `0.x` version | :white_check_mark: |
| Older `0.x` versions | :x: |
| Unreleased `main` branch snapshots | :x: |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. **Do not open a public GitHub issue, discussion, or pull request for security-sensitive reports.**

Send reports to **jamie.telin@gmail.com** and include, when possible:

- the affected OpenMUX version or release tag
- your macOS version
- a short description of the issue and its impact
- clear reproduction steps or a proof of concept
- any relevant logs, screenshots, or configuration details

We aim to acknowledge new reports within **5 business days** and will share follow-up updates as the investigation progresses.

If the report is accepted, we will work on a fix and coordinate disclosure when a patched release is available. If the report turns out not to be a security vulnerability, or only affects unsupported versions, we will let you know and may ask that it be redirected to the public issue tracker instead.
